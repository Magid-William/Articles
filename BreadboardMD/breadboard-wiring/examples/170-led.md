# 170-point mini - LED example

Series LED circuit with a 2-pin power header. P1 pin 1 is +, pin 2 is -.

Components & Wiring:

```text
| Location | Ref | Components | Value   | Reading | Note                        |
| -------- | --- | ---------- | ------- | ------- | --------------------------- |
| A1:A2    | P1  | header     | 2-pin   |         | pin1 +, pin2 -              |
| B1:F3    | J1  | jumper     | Red     |         |                             |
| G3:G6    | R1  | resistor   | 2.2kohm |         |                             |
| E6:F6    | D1  | LED        | Red     |         | anode F6, cathode E6        |
| D6:B2    | J2  | jumper     | Black   |         |                             |
```
